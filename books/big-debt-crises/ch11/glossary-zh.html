§11 · GLOSSARY · 中文

术语表不是词典抄写，而是 Part 3（及全书）反复出现的「剧情关键词」。每个词用生活类比压干：你在读图卡、归因条和危机叙事时，能快速对上号。1

先记住三对：泡沫/萧条，宽松/收紧，本币债/外币债——其余词多是这三对的零件。

balance of payments / 国际收支 — 一国居民与世界其余部分之间货物、服务、金融资产与其他支付的余额。变差像家庭入不敷出；变好则相反。

balance-of-payments crisis / 国际收支危机 — 国际收支恶化到实体在全球市场上缺乏足够购买力；现金与信用近乎耗尽。

bubble / 泡沫 — 债务、资产价格与增长自我强化但不可持续的阶段；关键词是「不可持续」，盛宴后必有账单。

capital inflows/outflows / 资本流入流出 — 跨境购买债券、股票、工厂等资本品的资金移动。外国人买本国资产为流入；本国人买外国资产为流出。

currency peg / 货币钉住 — 把本币固定在另一货币、货币篮子或黄金等资产上的汇率政策。

current account / 经常账户 — 出口减进口再加净收入；近似「净收入」。逆差须靠资本账户交易（借债或卖股权）弥补。

deleveraging / 去杠杆 — 降低债务负担的过程；归因分析拆开收入、通胀、还本、新借与利息滚入等贡献。

depression / 萧条 — 债务危机中资产与增长自我强化下跌的严重阶段；常发生在央行宽松空间受限时。

easing / stimulation / 宽松与刺激 — 让货币与信用更易得：降息、印钞、改监管，或财政增减支/税。收紧则相反。

FX debt / 外币债 — 以投资者母国货币以外的货币计价的债务——外币危机的放大器。

GDP / GDP gap / 产出与缺口 — GDP 是最终商品与服务总价值；缺口衡量相对「潜在产出」是过热还是松弛（不精确但常用）。

liquidity / 流动性 — 钱与信用是稀缺还是充裕。紧时连优质借款人也要付更高息。

M0 / money 0 — 已印出的基础货币：流通现金 + 央行准备金。

real / real FX / real rates — 「实际」剔除通胀。实际汇率看贵贱；实际利率为负意味着贷款人购买力在被稀释。

reflation / 再通胀 — 宽松货币政策帮助经济复苏的阶段——美丽去杠杆的货币侧。

reserves / 外汇储备 — 政府持有的外币或黄金储蓄，用于支付并影响本币供求与价格。

short/long rate · yield curve — 短端多指 ≤3 个月；长端常看 10 年国债。短端高于长端为倒挂，隐含短端将下行的定价。

更细的官方定义与图表口径以原书为准；此处刻意缩短，方便导读导航。2
